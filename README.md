# SpendSmart Lite - Personal Expense Tracker

SpendSmart Lite is a simple expense tracker website I made using Python and Django. The main idea of this project is to help users manage their daily expenses and keep track of their spending.

## Features

- User registration and login
- Add new expenses
- Edit and delete expenses
- Select expense categories like Food, Travel, Shopping, Education, Bills and Other
- Filter expenses by category
- View total expenses
- Each user can view and manage only their own expenses

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- Git and GitHub

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Atharv-c/spendsmart-lite.git
   ```

2. Open the project folder:

   ```bash
   cd spendsmart-lite
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the environment on Windows:

   ```bash
   venv\Scripts\activate
   ```

5. Install Django:

   ```bash
   pip install django
   ```

6. Run database migrations:

   ```bash
   python manage.py migrate
   ```

7. Start the server:

   ```bash
   python manage.py runserver
   ```

8. Open `http://127.0.0.1:8000/` in your browser.
